The MCP tools guidance says a human should remain able to deny tool
invocations, and clients should request confirmation for sensitive operations.
The consent prompt is implemented by the host before it calls get_disk_usage.
Tool descriptions and annotations from an untrusted server are treated as
untrusted because a malicious description could contain prompt-injection text
intended to influence the model or the user.
