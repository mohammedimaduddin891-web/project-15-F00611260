Reflection draft — paraphrase this

For an SRE agent, removing arbitrary outbound communication is usually the
cheapest way to break the trifecta. The agent can still read telemetry and
private operational data for diagnosis, but a hidden instruction cannot send
that data to an attacker unless an approved, destination-restricted outbound
tool exists.
